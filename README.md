# 🇴🇲 Oman National Day Celebration

### Celebrating Oman with Love & Code ❤️💚🤍

An interactive and animated web page created to celebrate **Oman National Day**, combining creativity, programming, and national pride.

Built using **HTML, CSS, and JavaScript**, this project expresses love for Oman through beautiful animations, fireworks, and a special programming-inspired message.

## ✨ Features

- 🇴🇲 Oman National Day themed design
- ❤️ Colors inspired by the Omani flag
- 🎆 Animated fireworks effects
- ⌨️ Interactive typing animation
- 🎉 Celebration button with special effects
- 📱 Responsive design for desktop and mobile
- 💻 Pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Interactive elements, typing effects, and fireworks

## 💻 How to Run

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. Enjoy the celebration! 🇴🇲
